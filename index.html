Daftar babi

Stok masuk otomatis dari Keuangan

Tidak perlu input stok di halaman ini. Catat pembelian pakan di menu Keuangan. Untuk Pelet 551 dan Shinta BR21, stok karung dikonversi ke kg (default 50 kg/karung). Untuk ampas tahu dan sayur, stok boleh tetap dalam satuan karung sehingga pemakaian 1/2 karung dicatat sebagai 0,5 karung.

Catat pemakaian harian

Catat hanya pemakaian harian. Pelet 551 dan Shinta BR21 dicatat dalam kg; ampas tahu dan sayur dapat dicatat dalam karung. Untuk setengah karung, masukkan 0,5. Pemakaian mengurangi stok dan dicatat sebagai biaya pakan.

Riwayat pemakaian harian

Stok pakan saat ini

Stok dihitung ulang dari seluruh riwayat pembelian pakan di Keuangan, lalu dikurangi seluruh pemakaian harian. Pelet 551 per karung dikonversi ke kg (isi karung sesuai transaksi, default 50 kg).

Catat kematian babi

Kematian bukan pengeluaran kas baru. Program mencatatnya sebagai kerugian aset ternak (estimasi berdasarkan modal beli per ekor) dan mengurangi jumlah babi hidup.

Penjualan dicatat sebagai pendapatan dan masuk ke perhitungan estimasi laba/rugi.

Rincian pengeluaran dan kerugian

Pembelian pakan yang menambah stok tidak dihitung lagi sebagai biaya pemakaian. Biaya pakan muncul dari catatan pemakaian harian agar tidak dihitung dua kali.

*Hasil operasi estimasi = kas masuk selain modal + penjualan − biaya operasional yang tercatat − kerugian kematian. Pembelian pakan yang masuk stok tidak dihitung sebagai biaya operasional sampai dipakai. Kartu pengeluaran menunjukkan uang keluar; rincian di bawah menunjukkan biaya/kerugian yang dihitung. Ini estimasi, bukan laporan akuntansi lengkap.

Sinkronisasi laptop dan HP

Penting: versi ini menyimpan data pada browser perangkat yang digunakan. Data belum otomatis tersinkron antarperangkat. Untuk sinkronisasi otomatis, aplikasi perlu dihubungkan ke database cloud dan dipasang pada alamat web yang sama. Jangan menganggap data sudah tersinkron sebelum koneksi cloud disiapkan.

Untuk saat ini, gunakan ekspor dan impor cadangan untuk memindahkan data secara manual. Simpan file cadangan di tempat aman, lalu impor di perangkat lain. Hindari mengedit data di dua perangkat sekaligus sebelum digabungkan.

Data awal dari buku catatan

Fungsi ini mengganti seluruh transaksi keuangan dengan data awal dari foto. Transaksi yang terhubung ke stok/babi dapat menjadi tidak sinkron; gunakan hanya untuk memulai ulang data.

Petunjuk menuju sinkronisasi otomatis

  1. Aplikasi perlu di-hosting di web agar laptop dan HP membuka aplikasi yang sama.
  2. Database cloud perlu dibuat dengan aturan akses pribadi, idealnya menggunakan akun masuk.
  3. Setelah koneksi cloud disiapkan, data keuangan, babi, stok, dan penjualan dapat disinkronkan otomatis.

Jangan menaruh password rahasia atau kunci admin database di file HTML publik.
